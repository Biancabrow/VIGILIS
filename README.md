# VIGILIS

O Vigilis consiste em um projeto de IOT cujo objetio é automatizar e monitorar o despertar do usuário. Para isso o protótipo realiza um despertar progressivo com aumento da iluminação, simulando o amanhecer, e do som, posteriomente é feito o monitoramento para garantir que o usuário permaneça acordado após desligar o alarme.

Neste repositório estão os arquivos com o código em C++, o código da montagem do circuito no Wokwi e o protótipo do app.
